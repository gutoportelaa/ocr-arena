- Registrar texto bruto e texto normalizado.

5) Arquitetura limpa

- Cada engine deve herdar de uma interface base comum.
- A orquestração deve ser desacoplada da implementação específica de cada engine.

7. SELEÇÃO AUTOMÁTICA DOS 20 PDFs
==================================================

Implemente um processo de amostragem inteligente dos PDFs.

7.1 Inventário inicial
Crie um script para varrer uma pasta grande de PDFs candidatos e gerar inventário com:
- nome do arquivo;
- caminho;
- hash SHA256;
- tamanho do arquivo;
- número de páginas;
- largura/altura média de página;
- presença de texto nativo;
- densidade de texto nativo;
- número estimado de imagens por página;
- proporção de páginas escaneadas;
- idioma provável;
- presença provável de tabela;
- rotação ou orientação irregular;
- heterogeneidade entre páginas.

7.2 Score de complexidade
Calcule um complexity_score por documento, com lógica transparente e configurável.
Use uma fórmula base semelhante a:

score =
0.20 * scan_ratio +
0.15 * image_density +
0.15 * table_density +
0.10 * rotation_irregularity +
0.10 * multi_column_likelihood +
0.10 * language_uncertainty +
0.10 * low_native_text_ratio +
0.10 * page_count_scaled

Normalize tudo entre 0 e 1.

7.3 Seleção dos 20 PDFs
Implemente uma seleção estratificada:
- 8 PDFs de alta complexidade;
- 6 PDFs de média complexidade;
- 4 PDFs de baixa complexidade;
- 2 outliers específicos.

Além disso:
- evite PDFs quase duplicados;
- maximize diversidade de tamanho, layout e tipo documental;
- salve selected_20.csv com justificativa por arquivo.

Se houver poucos PDFs disponíveis, degrade graciosamente e documente o critério usado.

12. ANÁLISE SEMÂNTICA AUTOMÁTICA
==================================================

Implemente análise semântica automática das saídas para apoiar a revisão humana.

Como nem sempre teremos ground truth, implemente três estratégias:

12.1 Consenso entre modelos
- Compare a similaridade semântica entre as saídas dos diferentes modelos para a mesma página/documento.
- Gere uma matriz de concordância.

12.2 Similaridade textual e estrutural
Use métricas como:
- cosine similarity via embeddings;
- Levenshtein ratio;
- Jaccard de n-grams;
- sobreposição de headings;
- sobreposição de blocos/tabulações.

12.3 Score composto
Crie um semantic_quality_score por saída, combinando:
- concordância com o consenso;
- completude de texto;
- baixa taxa de ruído;
- preservação estrutural.

Se possível, use um modelo local de embeddings para comparação.
Se optar por Ollama para análise estrutural/semântica, faça isso de forma reprodutível e com schema fixo.
